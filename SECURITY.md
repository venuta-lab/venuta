# Security

## Reporting a problem

Please don't open a public issue for a security problem. Report it privately instead: on the
repository's **Security** tab, choose **Report a vulnerability**. Say what you found, how to
reproduce it, and which version you used.

You'll hear back within a week. A fix ships as a new version, and the report is credited unless
you'd rather it wasn't.

## What to report

- Anything that lets a web page, a playlist file, a theme file or a link make Venuta read, write
  or run something it shouldn't.
- A way around the update signature: Venuta installs only updates signed with its own key.
- Anything that sends your data somewhere it shouldn't go. Venuta has no account and no
  tracking; the only requests it makes are the lookups and online sources listed in
  Settings › About.

## Supported versions

Only the latest release gets fixes. Venuta checks for updates once a day, and installs one only
when you choose.
